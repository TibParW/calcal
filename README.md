# 🥗 calCal - AI Calorie Calculator

เว็บแอปพลิเคชันตรวจจับและประเมินแคลอรีจากรูปถ่ายอาหารด้วย **Vision AI (Google Gemini Flash)** ออกแบบมาให้ใช้งานบนมือถือเป็นหลัก (Mobile-First) จำข้อมูลแยกตามเครื่องผู้ใช้ (LocalStorage) และตัดยอดแคลอรีอัตโนมัติทุกเที่ยงคืน (00:00 น.) พร้อมนำไป Deploy บน Vercel ได้ทันที!

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 📸 **ถ่ายรูปอาหารแล้วสแกนทันที**: สั่งเปิดกล้องหลังมือถือทันที หรือเลือกรูปจากคลังภาพ
- 🏷️ **สแกนฉลากโภชนาการหลังซอง (Nutrition Label OCR - แม่นยำ 100%)**: สแกนตารางข้อมูลโภชนาการหลังซองขนม เครื่องดื่ม หรือกล่องอาหารพร้อมทานจาก 7-Eleven อ่านค่าจริงได้แม่นยำ 100%
- 🍱 **ตรวจจับหลายเมนูใน 1 รูป (Multi-dish Detection)**: ถ่ายรูปเดียวที่มีทั้งจานหลัก ชามซุป และแก้วน้ำ AI แยกเป็นการ์ดแต่ละเมนู มี Checkbox `[✓]` ให้เลือกบันทึกหรือตัดรายการออกได้อิสระ
- 🎯 **ระดับความมั่นใจของ AI พร้อมเหตุผล (Confidence Tag with Reason)**: แสดงระดับความมั่นใจ (สูง/ปานกลาง/ต่ำ) พร้อมระบุเหตุผล เช่น มีน้ำมันเคลือบ หรือเป็นซุปขุ่นมองไม่เห็นเนื้อสัตว์
- 📝 **แท็กลัด & หมายเหตุสั่ง AI คำนวณใหม่ (Meal Notes & Quick Tags)**: มีปุ่มแตะด่วน เช่น `[ไม่ใส่น้ำมัน]`, `[ไม่เอาหนัง]`, `[หวานน้อย]`, `[ข้าวน้อย]` หรือพิมพ์ระบุเอง แล้วสั่งให้ AI คำนวณพลังงานใหม่ได้ทันที
- ⚖️ **ปรับสัดส่วนได้ดั่งใจ**: ปรับขนาดจาน `[ x0.8 | x1.0 | x1.3 ]` ระบบคำนวณแคลอรีและสารอาหารตามสัดส่วนให้อัตโนมัติ หรือพิมพ์แก้ตัวเลขเองได้
- 🧮 **เครื่องคำนวณเป้าหมายเฉพาะบุคคล (BMR & TDEE Calculator)**: คำนวณความต้องการพลังงานตามสูตร Mifflin-St Jeor พร้อมตั้งเป้าหมายลดไขมัน รักษาน้ำหนัก หรือเพิ่มกล้ามเนื้อ แล้วกดนำไปใช้กับ Dashboard ได้ในคลิกเดียว
- 📈 **กราฟสรุปภาพรวม 7 วันล่าสุด (Weekly 7-Day Chart)**: กราฟแท่งเปรียบเทียบแคลอรีจริงกับเป้าหมาย แสดงค่าเฉลี่ยต่อวัน และแตะดูมื้ออาหารของแต่ละวันได้ทันที
- 💾 **ระบบจัดเก็บในเครื่องแบบเบาพิเศษ (Ultra-Compact Local Storage)**:
  - **โหมด Ultra-Light**: บันทึกเฉพาะตัวเลขและข้อความ ไม่เก็บรูป ใช้พื้นที่เพียง ~0.2 KB/มื้อ (กิน 1 ปีใช้ไม่ถึง 0.3 MB)
  - **โหมด Micro-Thumbnail**: ย่อรูปเหลือ 80x80 px จิ๋วมาก (~2-3 KB/มื้อ)
  - **มาตรวัดความจุ (Storage Meter)**: แสดงพื้นที่ใช้งานจริง พร้อมปุ่มล้างรูปภาพคืนพื้นที่
  - **ส่งออกข้อมูล (Export CSV & JSON)**: ส่งออกเป็นตาราง Excel ภาษาไทยเปิดอ่านได้ทันที (UTF-8 BOM)
- 🔄 **จำแยกตามเครื่อง & ตัดรอบ 00:00 น.**: ไม่ต้องสมัครสมาชิก ไม่ส่งข้อมูลส่วนตัวขึ้นฐานข้อมูลส่วนกลาง ขึ้นวันใหม่ยอดแคลอรีจะเริ่มนับ 0 อัตโนมัติ
- 📱 **พร้อมติดตั้งเป็น PWA บนหน้าจอมือถือ**: เพิ่มลงหน้าจอโฮม (Add to Home Screen) เปิดใช้งานได้เหมือนแอปแท้แบบไร้ขอบเบราว์เซอร์

## 🚀 วิธีเปิดใช้งานในเครื่อง (Local Development)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ตั้งค่า Gemini API Key
สร้างไฟล์ `.env.local` ขึ้นมาในโฟลเดอร์โปรเจกต์:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
> สามารถขอรับ Gemini API Key ฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/app/apikey)

*(หมายเหตุ: หากไม่ได้ใส่ใน `.env.local` สามารถกดปุ่ม **ตั้งค่า (รูปฟันเฟือง)** บนหน้าเว็บ แล้ววาง API Key ในหน้าเว็บได้เช่นกัน)*

### 3. เริ่มรันเว็บเซิร์ฟเวอร์
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

## 🌐 วิธีนำขึ้น Vercel เพื่อเปิดใช้งานบนมือถือได้ทุกที่

Vercel ให้บริการโฮสต์เว็บแอปฟรี รองรับ Next.js ได้สมบูรณ์แบบ 100%:

### ขั้นตอนที่ 1: อัปโหลดโค้ดขึ้น GitHub
1. สร้าง New Repository บน [GitHub](https://github.com/)
2. รันคำสั่งในโฟลเดอร์โปรเจกต์นี้:
```bash
git init
git add .
git commit -m "Initial commit of calCal"
git branch -M main
git remote add origin https://github.com/TibParW/calcal.git
git push -u origin main
```

### ขั้นตอนที่ 2: เชื่อมต่อและ Deploy บน Vercel
1. เข้าไปที่ [Vercel.com](https://vercel.com/) แล้วล็อกอินด้วยบัญชี GitHub
2. คลิกปุ่ม **"Add New..."** → เลือก **"Project"**
3. เลือก Repository `TibParW/calcal` แล้วกด **Import**
4. ในส่วน **Environment Variables**:
   - **Key**: `GEMINI_API_KEY`
   - **Value**: วาง API Key ของคุณที่ได้จาก Google AI Studio
5. กดปุ่ม **"Deploy"**
6. รอประมาณ 1 นาที จะได้ลิงก์โดเมนเว็บไซต์ เช่น `https://calcal-xxx.vercel.app` ซึ่งสามารถแชร์หรือเปิดบนมือถือได้ทันที

## 📱 วิธีติดตั้งลงหน้าจอมือถือ (Add to Home Screen)

เมื่อได้ลิงก์จาก Vercel หรือเซิร์ฟเวอร์ของคุณแล้ว สามารถทำให้อยู่บนหน้าจอมือถือเหมือนแอปแท้ๆ:

### บน iPhone (iOS / Safari)
1. เปิด Safari แล้วเข้าลิงก์เว็บของคุณ
2. แตะปุ่ม **แชร์ (Share)** ที่แถบด้านล่าง (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น)
3. เลื่อนลงมาเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. แตะ **"เพิ่ม" (Add)** ที่มุมขวาบน

### บน Android (Chrome)
1. เปิด Google Chrome แล้วเข้าลิงก์เว็บของคุณ
2. แตะปุ่มจุดสามจุด **(⋮)** ที่มุมขวาบน
3. เลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home Screen)** หรือ **"ติดตั้งแอป" (Install App)**

## 🛠️ โครงสร้างโปรเจกต์ (Tech Stack)

- **Framework**: Next.js 15 (App Router, React 19, TypeScript)
- **Styling**: Tailwind CSS (Mobile-First, Dark mode support)
- **AI Core**: Google Gemini 1.5 Flash Vision API (`@google/generative-ai`)
- **Icons**: Lucide React
- **Storage**: Browser LocalStorage (Zero-database architecture)
